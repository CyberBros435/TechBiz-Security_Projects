This project documents my completion of the **Understanding Logs & Log Analysis Basics** task as part of the **TechBiz Security SOC Analyst Internship**.

The project focuses on understanding how a SOC analyst works with logs to identify normal behavior, suspicious activity, patterns, anomalies, and deviations from an established baseline.
