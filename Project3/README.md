## Project Overview

This project covers the foundation of building a basic cybersecurity and SOC laboratory environment.

The internship task required:

- Installing Oracle VirtualBox
- Setting up a Kali Linux or Ubuntu environment
- Setting up a Windows analysis environment
- Understanding virtual machine networking
- Testing connectivity between systems
- Completing the required TryHackMe Windows Fundamentals learning activity
- Collecting screenshot evidence of the practical work

The purpose of the lab is to create an environment that can later be used for logs, SIEM monitoring, network analysis, and security investigations.
